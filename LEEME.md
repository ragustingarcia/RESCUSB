# RESCUSB | Empezar acá

**Tu pendrive de rescate. Preparado para cuando algo falla.**

1. Cerrá las ventanas de versiones anteriores del preparador.
2. Conectá el pendrive y abrí **INICIAR.bat**. Si Windows pide administrador, aceptá el permiso.
3. Elegí **Armar mi pendrive completo**, seleccioná tu USB y dejalo conectado.
4. RESCUSB comprueba las siete fuentes y obtiene automáticamente los enlaces y hashes oficiales de Windows.
5. Revisá los datos y escribí **BORRAR seguido de la serie** mostrada para autorizar el borrado de ese pendrive.
6. Esperá hasta el resultado. Si se interrumpe, elegí **Continuar** la próxima vez.
7. Con el contenido marcado LISTO, expulsá el USB y elegilo en el menú de arranque del equipo.

Si Microsoft no entrega el enlace de Windows, RESCUSB te ofrece preparar ahora las otras herramientas y agregar Windows después con **Continuar**, o bajar la ISO oficial desde el navegador.

El programa trabaja en una sola ventana de terminal. No exige desconectar/reconectar el USB, pegar enlaces ni escribir hashes. La primera preparación elimina todos los archivos del pendrive elegido. Si una fuente necesaria no está disponible, se informa antes del borrado.
