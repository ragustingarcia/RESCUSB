01 / ELEGÍ

Tu pendrive, bien identificado.

Solo se ofrecen USB extraíbles compatibles. Los discos principales quedan fuera de la lista.

02 / CONFIRMÁ

El borrado es una decisión tuya.

Primero se comprueban las fuentes. Después se pide la serie para autorizar ese dispositivo.

03 / DEJALO TRABAJAR

Descargas que pueden continuar.

Las imágenes incompletas se conservan. Un resultado parcial nunca se presenta como completo.

Siete herramientas. Un solo pendrive.

Preparar el USB elimina su contenido. La terminal muestra el dispositivo y pide confirmación antes de hacerlo.

Windows requiere que Microsoft autorice una sesión de descarga. Si una fuente falla, RESCUSB lo informa antes de borrar. El arranque final se prueba en el equipo de destino.
